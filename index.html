臺中惠民扶輪社｜扶輪日售票暨入場系統 v1.1.0 更新部署步驟 ================================================== 【本版檔案】 1. 扶輪日售票系統_Code_v1.1.0.gs → Google Apps Script 後端 2. 扶輪日售票系統_Index_v1.1.0.html → rotary-day GitHub Pages 售票前端 3. 扶輪日報到系統_Index_v4.1.0.html → 現場報到 GitHub Pages 前端 -------------------------------------------------- 一、先更新 GAS 後端 -------------------------------------------------- 1. 打開「扶輪入場名單」Google Sheets。 2. 擴充功能 → Apps Script。 3. 將目前 Code.gs 內容完整換成「扶輪日售票系統_Code_v1.1.0.gs」。 4. 儲存。 5. 手動執行一次 setupRotaryDaySystem()。 - 這一步會補上 v1.1.0 新欄位與設定。 - 不會刪除既有訂單、票券、付款紀錄。 6. 部署 → 管理部署作業 → 編輯既有 Web App → 版本選「新版本」→ 部署。 ★ 請用「編輯既有部署」方式，這樣原本 Web App URL 不會改變。 v1.1.0 會新增／補齊： - 訂單：身分、所屬扶輪社、預填帳號末五碼 - 系統設定：售票開關、銀行代碼、分行、其他通知 Email 等 - 若舊票價仍為 0，會自動改為 2200。 - 若 FRONTEND_URL 還是舊 rotaryday，會修正為： https://sozajan-design.github.io/rotary-day/ -------------------------------------------------- 二、更新「扶輪日售票系統」GitHub Pages -------------------------------------------------- Repository：rotary-day 1. 打開 rotary-day repository。 2. 將「扶輪日售票系統_Index_v1.1.0.html」內容放入 repository 根目錄的 index.html。 3. Commit changes。 4. 等 GitHub Pages 重新部署。 網址應為： https://sozajan-design.github.io/rotary-day/ ★ 如果你目前實際使用的 GAS Web App URL 與程式檔中的 DEFAULT_API_URL 不同， 請把 index.html 最上方 DEFAULT_API_URL 改成目前可正常運作的 Web App URL。 -------------------------------------------------- 三、更新「現場報到系統」前端 -------------------------------------------------- 1. 到目前報到系統使用的 GitHub repository。 2. 將「扶輪日報到系統_Index_v4.1.0.html」放入該 repo 的 index.html。 3. Commit changes，等待 Pages 更新。 本版報到功能沒有移除 QR Code： - 每一張票仍有獨立 Ticket ID + QR Code。 - 現場掃 QR Code 後完成報到。 - 同一張票再次掃描會顯示重複報到。 - 本次主要更新頁尾品牌為：日安匕禾 / Beaver Tech System。 -------------------------------------------------- 四、執秘第一次登入後先做「活動設定」 -------------------------------------------------- 售票首頁最下方 → 執秘管理入口 登入後有三區： 1. 待核帳 2. 全部訂單 3. 活動設定 請先確認： - 每張票價 - 活動日期／時間／地點 - 售票是否開放 - 銀行／銀行代碼／分行 - 匯款戶名／帳號 - 執秘 Email - 其他通知 Email（如需要） - 前端網址 - 管理密碼 -------------------------------------------------- 五、v1.1.0 建議測試流程 -------------------------------------------------- A. 購票人 1. 手機登入或建立帳號。 2. 選身分：扶輪社友／寶眷、貴賓、其他。 3. 若選扶輪社友／寶眷，填所屬扶輪社。 4. 選張數、收據抬頭。 5. 「匯款帳號後五碼」可先填，也可以留白。 6. 建立訂單。 7. 完成銀行轉帳後，按「我已匯款」。 8. 匯款日期預設今天、金額預設訂單總額；輸入後五碼後送出。 B. 執秘測試 1：正常收到款項 1. 進「待核帳」。 2. 按「已收到款項・確認出票」。 3. 檢查： - 訂單變為已確認 - 產生正確張數 Ticket ID - 寫入「活動名單」 - 收到電子收據 Email - 收到同一封內含多張 QR Code 的票券 Email C. 執秘測試 2：查無款項 1. 購買人再次建立測試訂單並按「我已匯款」。 2. 執秘按「目前查無款項」。 3. 系統應： - 保留這次付款回報歷史，不刪除 - 訂單回到「等待匯款」 - 購買人的「我已匯款」按鈕重新出現 - 不產生 QR Code - 寄 Email 告知目前尚未查得款項 4. 購買人完成匯款後可以再次按「我已匯款」。 D. 執秘測試 3：資料有疑問 1. 待核帳訂單按「資料有疑問」。 2. 輸入原因，例如「應收 4,400，目前只查到 2,200」。 3. 訂單暫停出票並通知購買人。 4. 此筆仍留在執秘待核帳區，之後可再： - 確認收到款項並出票，或 - 按目前查無款項退回等待匯款。 -------------------------------------------------- 六、本版品牌 -------------------------------------------------- 所有售票前端頁面與報到系統頁尾統一顯示： 日安匕禾 Beaver Tech System ==================================================
